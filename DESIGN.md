# Design

## Visual Identity
L.A.P. (Latin American Performance) uses a refined, modern-minimalist aesthetic. It balances the raw energy of performance arts with the clean discipline of a high-end digital publication.

## Typography

- **Display/Headings**: General Sans (Medium/Semibold). Used for impact and clarity.
- **Body**: Satoshi (Regular). Optimized for long-form readability with high legibility.
- **Monospace**: System mono for technical/meta elements.

## Color Palette (OKLCH)

- **Ink (Foreground)**: `oklch(0.98 0 0)` - Pure white for high-contrast reading on dark surfaces.
- **Paper (Background)**: `oklch(0.12 0 0)` - A deep, near-black neutral that provides a sophisticated backdrop.
- **Accent (Primary)**: `oklch(0.62 0.25 285)` - A vibrant electric violet/purple (`#8a2be2`) used for status, actions, and highlights.
- **Muted**: `oklch(0.45 0 0)` - Mid-tone gray for metadata and secondary info.

## Components

### Surface
- **Borders**: 1px solid `oklch(0.25 0 0)` (subtle divider).
- **Radius**: 0px (Sharp, professional edges).

### Buttons
- **Action**: High-contrast, sharp edges, purple-to-black hover states.
- **Ghost**: Text-only with subtle background shifts.

## Layout
- **Container**: Max-width `4xl` (approx 65-75ch) for the reading column.
- **Spacing**: 8px (0.5rem) base grid. Section gaps usually at 64px-96px (4rem-6rem).
